Exporting Elastic Network Interfaces
====================================

Scenarios
---------

This section describes how to export the list of elastic network interfaces, including their private IP addresses, IDs, and VLAN IDs.

Exporting the List of Elastic Network Interfaces
------------------------------------------------

#. Log in to the management console.

#. Click |image1| in the upper left corner and select the region and project.

#. In the upper left corner of the page, click |image2| to expand the service list and choose **Network** > **Virtual Private Cloud**.

   The VPC list is displayed.

#. In the navigation pane on the left, choose **Virtual Private Cloud** > **Network Interfaces**.

   The network interface list is displayed.

#. In the upper left corner above the network interface list, click **Export**.

   -  **Export selected data to an XLSX file**: Select one or more network interfaces to export their information.
   -  **Export all data to an XLSX file**: Export information about all the network interfaces in the current region.

   The system will automatically export information about the network interfaces as an Excel file to a local directory.
